⚙️ Google Cloud Managed Services Specifications

Technical parameters, networking, storage options, and region configurations for all deployed resources.

🚀 Google Cloud Run Fleet

  • Region: asia-south2 (Delhi)
  • Container Port: 8080 across all services
  • api-gateway: min: 1, max: 3, concurrency: 80, timeout: 60s
  • Microservices: min: 0, max: 3, concurrency: 80, timeout: 300s
  • CPU Boost: Enabled for fast cold starts
  • Startup Probes: /actuator/health/readiness with 10s initial delay

🐘 Cloud SQL PostgreSQL 15

  • Instance Name: t2g-payments
  • Database Name: t2g_payments
  • DB User: t2g_payment_app
  • Engine: PostgreSQL 15 on db-f1-micro tier
  • Storage: 10GB SSD with automated daily backups
  • Socket Factory: JDBC Socket Factory via roles/cloudsql.client

🪣 Google Cloud Storage

  • Security: Uniform bucket-level access enforced
  • Media Bucket: gs://travel2go-media-bucket
  • Email Bucket: gs://travel2go-email-archives
  • Admin Role: Granted exclusively to t2g-media
  • Viewer Role: Scoped strictly to reader services

🔥 Firestore & Artifact Registry

  • Firestore Mode: Datastore / Native mode in asia-south2
  • Role: roles/datastore.user on 8 data services
  • Registry Repo: cloud-run-source-deploy (Docker)
  • Tagging Scheme: SHA-pinned immutable container tags
  • Firebase Hosting: Hosts React 19 SPA with edge CDN caching
